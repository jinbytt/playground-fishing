# 경품낚시 'ㅇ')/

이벤트 키오스크용 미니게임. 파일 하나(`index.html`)로 동작하며 폰트·이미지가 모두 내장되어 있어 인터넷 없이도 실행됩니다.

## 실행
- `index.html`을 브라우저(Chrome/Edge 권장)로 열면 끝.
- 키오스크는 전체화면(F11) 또는 Chrome `--kiosk` 모드 권장.

## 흐름
인트로 → 게이지 타이밍 던지기 → 입질(!) → 연타 끌어올리기 → 경품 결과 → 전화번호 입력 → 접수 완료

## 설정 (`index.html` 상단 `SKIN`)
- `prizes` : 경품 목록. `weight`가 클수록 자주 나옴, `farBonus`는 멀리 던졌을 때 배수, `image`에 사진 넣으면 이모지 대신 표시
- `texts` : 인트로 문구
- `balance` : 바늘 속도, 입질 대기 시간, 연타 횟수 등
- `showOdds` : `true`면 인트로에 당첨 확률 표시

## 저장 연결
전화번호 접수 시 `onClaim(entry)`가 호출됩니다 (`{ phone, prize, time }`). 서버/스프레드시트 저장은 이 함수에 연결하세요.
